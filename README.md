# BusGo – Luxury Bus Travel Booking Platform

## Overview
A modern full-stack bus booking platform with responsive UI, secure authentication, booking management, payment workflow, route explorer, community features, notifications, rewards, and multilingual support.

## Features
- User Authentication
- Bus Search
- Seat Selection
- Passenger Details
- Secure Payment
- Booking Confirmation
- My Bookings
- Route Explorer
- Community
- Notifications
- Rewards
- Ratings & Reviews
- Help Center
- Dark Mode
- Multi-language Support
- Responsive Design

## Installation

Frontend:
npm install
npm run dev

Backend:
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
